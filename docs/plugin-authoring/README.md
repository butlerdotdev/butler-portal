# Plugin authoring

Cross-cutting authoring guidance for butler-portal plugins. Each page
covers a seam or capability butler-portal provides on top of upstream
Backstage. For the structural side of writing a plugin (frontend
components, backend routes, dynamic-plugin packaging), start with
[dynamic-plugins/authoring](../dynamic-plugins/authoring.md).

## Contents

- [Authorization](./authorization.md) - how a plugin declares
  permissions and enforces them at request time. Reads
  [Architecture: Permissions](../architecture/permissions.md) as
  background.
